

# Monitoring and Logs

## Objective
Detect suspicious activity in Active Directory.

---

## Use Event Viewer

Check:
- Security logs
- System logs

---

## Important Events

- Successful login
- Failed login
- Account lockout
- Password reset
- User created
- Group membership changed

---

## SIEM Tools
- Splunk
- Wazuh
- Microsoft Sentinel

---

## What to Watch
- Many failed logins
- Login after hours
- Privileged group changes
- New admin accounts

---

## What I Learned
Logs help detect attacks early.
