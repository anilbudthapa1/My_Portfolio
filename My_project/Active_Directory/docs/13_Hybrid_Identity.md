
# Hybrid Identity

## Objective
Understand modern identity with cloud + on-prem AD.

---

## Components

## On-Prem AD
Traditional internal directory.

## Microsoft Entra ID
Cloud identity platform.

## Sync
Users synced from on-prem to cloud.

---

## Features

- Single Sign-On
- Conditional Access
- MFA
- Self-service password reset

---

## Why Companies Use Hybrid
- Legacy apps stay on-prem
- Cloud apps use Entra ID
- Better flexibility

---

## What I Learned
Modern enterprises often use both on-prem AD and cloud identity together.
