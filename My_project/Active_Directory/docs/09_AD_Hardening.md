

# Active Directory Hardening

## Objective
Secure AD against common attacks.

---

## Security Tasks

- Rename Administrator account
- Disable Guest account
- Strong password policy
- Restrict RDP
- Enable MFA concepts
- Apply patches
- Use separate admin accounts
- Enable auditing

---

## Important Concepts

## Least Privilege
Only give needed access.

## Tiered Admin
Separate workstation admins from server admins.

## LAPS
Manage local admin passwords securely.

---

## Risks if Weak
- Privilege escalation
- Password attacks
- Lateral movement

---

## What I Learned
AD security is as important as AD functionality.
